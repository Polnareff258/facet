### ⚠️ 重点提示：`cs-monitor` 的 MIT 徽章不等于 MIT 授权

该项目的 README 带有 `License: MIT` 徽章，但：

- 仓库根目录**没有 LICENSE / LICENCE / COPYING 文件**；
- GitHub API 对该仓库返回 `license: None`（GitHub 未能识别出许可）。

按默认著作权规则，「无许可声明」意味着**保留所有权利**，并非自动变为 MIT。
README 徽章是一句自述，不构成完整的许可授予文本。

**本项目的处理：**
- **未复制 `cs-monitor` 的任何代码**；
- 仅参考了它的**架构思路**（适配器分层、SQLite 表设计方向、告警冷却概念）——
  思路与方法不受版权保护，且这些设计在本项目中是独立实现的；
- 如果你打算复用它的代码，请先向作者取得明确授权，或仅把它当作阅读材料。

### GPL-3.0 项目的处理（`CS2TradeMonitor`）

GPL-3.0 是强 copyleft：若你**分发**了包含其代码的衍生作品，整个作品需以 GPL-3.0 分发。
本项目的处理：

1. **未复制其任何代码**。从它提取的是**接口事实**：
   接口路径、请求头字段名、字段形状约束、错误码语义。
   这类事实性信息不构成受版权保护的表达，本项目据此**独立重写**了 Python 实现。
2. **未随包分发其资源文件**。`refs/` 已加入 `.gitignore`，参考项目源码与资源
   只存在于你本地、由你自行克隆。
3. `csmon seed` 命令会**可选地**读取其随包附带的
   `hot-top1000.youpin-mapping.json.gz`（一个 `marketHashName → yyyp_id` 的事实映射表）。
   该操作是**运行时的本地读取**，且资源不存在时静默跳过 —— 本项目不把它打进分发物。
   若你要对外分发本工具，建议**自行重建该映射**（通过公开接口按关键词解析 templateId），
   而不是附带 GPL 项目的资源文件。
4. 最保守的做法：不运行 `csmon seed`，改用 CLI 显式指定 ID
   （`python -m csmon watch add "名称" --youpin-id 822`）。

### MIT 项目（`cs2-inventory-manager`、`buff-price-alert`）

MIT 允许复用与再分发，只需保留版权声明与许可文本。本项目同样只提取了接口事实，
未复制代码；若你后续要直接搬运其代码片段，记得在其许可要求下保留署名。

## 「接口知识」与「代码」的界限

本项目对这个界限的处理原则：

| 内容 | 性质 | 本项目做法 |
| --- | --- | --- |
| 接口 URL、请求方法、参数名、响应字段名 | 事实 | 直接使用 |
| 错误码含义（如悠悠有品 `84103` 未登录、`85100` 风控） | 事实 | 直接使用 |
| 请求头形状约束（`DeviceId` 24 位等） | 事实 | 直接使用 |
| 具体实现代码、函数组织、注释文案 | 受版权保护的表达 | **未复制，独立重写** |
| 项目附带的数据资源文件（映射表等） | 可能是受保护的汇编作品 | **不随包分发**，仅可选本地读取 |

如果你对某项的定性有疑虑，最安全的做法是只保留事实、丢弃表达——这也是本项目采取的路径。
